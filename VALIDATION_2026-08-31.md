## Final manual hardening before merge

The final manual repository and publication audit found and corrected additional issues that automated compilation alone would not have resolved:

1. **Private-asset staging defense.** `.gitignore` did not originally exclude `data/audit/private/`. CI already rejected tracked private audit material, but the ignore rule was added as defense in depth so the private fixture is not casually staged in the public repository.
2. **Rights-safe ZIP provenance ambiguity.** `scripts/export_rights_safe.py` originally could include the tracked root `RELEASE_PROVENANCE.json` and then write a generated record under the same archive member name. Because ZIP permits duplicate names, the exporter was changed to replace the tracked provenance entry with exactly one generated record and to fail if any duplicate archive member exists.
3. **Export provenance semantics.** The exporter now distinguishes the historical reconstruction checkpoint from build validation and states only that the export operation itself does not verify a web build.
4. **Public Sources-page status.** The Sources page still contained historical text saying a genuine Next.js production build remained unverified. That public-facing statement was corrected to the permanent-CI evidence while preserving browser/accessibility/deployment as open launch gates.
5. **Temporary workflow cleanup.** The final branch workflow directory was verified to contain only `.github/workflows/ci.yml`.
6. **Scientific/publication language.** Industry, occupation, methodology, Sources, technical essay, homepage, and `docs/RESULTS.md` were reviewed for causal/productivity/efficiency overstatement. Causal terms remain only as explicit non-claims, prohibited interpretations, or limitations.

The final PR changed-file audit contained no private RPS audit fixture and no temporary repair/reconciliation workflow.
